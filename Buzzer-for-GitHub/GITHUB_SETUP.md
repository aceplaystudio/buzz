# Phone buzzer page ko GitHub Pages par lagana (Roman Urdu)

File: `C:\Users\GDD1\Downloads\Buzzer-for-GitHub\index.html` (yeh `dist/buzzer/index.html` ki copy hai).
Yeh page public hoga. Is mein sirf buzzer hai, game ya sawal nahi.

## 1. GitHub account banana (aap khud banayenge)
1. Browser mein **github.com/signup** kholein.
2. Shop/company wali email likhein, password banayein.
3. Username: **aceplaystudio** (agar le liya gaya ho to **aceplaystudio-games**). Yeh naam buyers ko link mein nazar aayega, is liye Sir se pooch lein.
4. Email par aaya code daal kar account verify karein. Free plan chunein.

## 2. Repository banana
1. Upar right par **+** → **New repository**.
2. Repository name: **buzz**
3. **Public** chunein.
4. **Add a README file** par tick lagayein.
5. **Create repository** dabayein.

## 3. File upload karna
1. Repository page par **Add file** → **Upload files**.
2. `Downloads\Buzzer-for-GitHub\index.html` ko mouse se is page par kheench kar chhor dein (drag & drop).
3. Neeche **Commit changes** dabayein.

## 4. GitHub Pages on karna
1. Repository mein upar **Settings** → left side **Pages**.
2. "Source" mein **Deploy from a branch**.
3. Branch: **main**, folder: **/ (root)** → **Save**.
4. 1–2 minute baad page ke upar link aayega: `https://aceplaystudio.github.io/buzz/`

## 5. Claude ko batayein
Link Claude ko bhej dein. Claude game mein yeh link lagayega, dobara build karega aur test karega.

Baad mein buzzer page badalna ho to: repository mein `index.html` par click → pencil ki jagah **…** → **Upload files** se nayi file daal kar **Commit changes**.
